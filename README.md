# Yisrael Date

Calendário baseado na Torá com referências à Halachá, apresentando o ciclo anual, datas hebraicas, tempos sagrados (Zmanim) e porções de leitura bíblica.

## Características Técnicas

- **100% Client-Side:** Todo o cálculo de datas, horários e festas decorre no dispositivo do utilizador.
- **Offline First (PWA):** Instalação direta no telemóvel e computador com suporte autónomo sem internet.
- **Privacidade Absoluta:** Sem armazenamento de dados em servidores externos, sem rastreio de identidade.
- **Resguardo Haláchico:** Pausa automática de doações no Shabat e em datas sagradas de Yom Tov.
